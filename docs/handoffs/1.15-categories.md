# [1.15] Category taxonomy + pixel icons

**Author:** Flash (Gemini 3.8 Flash, Antigravity)  
**Branch:** `flash/1.15-categories`

## What changed

1. **Category Taxonomy Seed File (`data/seed/categories.json`)**:
   - Seeded all 23 top-level categories and 93 sub-categories (116 entries total) directly from the "Categories" table in `docs/product-plan.md`.
   - Each entry contains:
     - `slug`: Unique, clean kebab-case identifier (e.g. `games`, `browser-games`, `productivity`, `ai-and-agents`).
     - `name`: Clean human-readable display title (e.g. `Games`, `Browser games`).
     - `parentSlug`: `null` for top-level categories, or the parent category's slug for sub-categories.
     - `iconKey`: `"cat-<slug>"` for top-level categories (e.g. `cat-games`, `cat-productivity`), `null` for sub-categories.
     - `description`: A concise, plain-English descriptive sentence.
     - `position`: Ordered by tens for top levels (10, 20, 30 ... 230) with sub-categories nestled consecutively under their parent (11, 12 ...), matching `ORDER BY c.position, c.name` in the catalog API.

2. **Pixel Icons (`packages/ui/src/icons/CategoryIcons.tsx` & `index.ts`)**:
   - Designed 23 custom 16×16 pixel icons, one for each top-level category:
     - `CatGamesIcon` (`cat-games`): Retro gamepad controller with D-pad and action buttons.
     - `CatProductionIcon` (`cat-production`): Audio mixer tracks with fader sliders.
     - `CatToolsAndUtilitiesIcon` (`cat-tools-and-utilities`): Spanner / wrench and screwdriver.
     - `CatSuitesIcon` (`cat-suites`): 2x2 modular suite app tiles.
     - `CatProductivityIcon` (`cat-productivity`): Clipboard with dual checkmarks.
     - `CatDeveloperToolsIcon` (`cat-developer-tools`): Code syntax brackets and slash (`< / >`).
     - `CatAiAndAgentsIcon` (`cat-ai-and-agents`): Robot head with antenna and glowing eyes.
     - `CatCreativeAndDesignIcon` (`cat-creative-and-design`): Painter's palette with color spots and thumb hole.
     - `CatFinanceAndMoneyIcon` (`cat-finance-and-money`): Gold coin with currency glyph.
     - `CatHealthAndFitnessIcon` (`cat-health-and-fitness`): Heart with active ECG pulse wave.
     - `CatEducationAndLearningIcon` (`cat-education-and-learning`): Graduation cap (mortarboard) with tassel.
     - `CatHomeAndLifeIcon` (`cat-home-and-life`): House with chimney, window, and door.
     - `CatSocialAndCommunityIcon` (`cat-social-and-community`): Dual chatting speech bubbles.
     - `CatBusinessAndOpsIcon` (`cat-business-and-ops`): Classic briefcase with brass buckle clasps.
     - `CatDataAndAnalyticsIcon` (`cat-data-and-analytics`): Ascending bar chart with trendline dots.
     - `CatMediaAndEntertainmentIcon` (`cat-media-and-entertainment`): Media player display with play symbol.
     - `CatHardwareAndIotIcon` (`cat-hardware-and-iot`): Microchip IC with contact pins and silicon die.
     - `CatPrivacyAndSecurityIcon` (`cat-privacy-and-security`): Padlock with shackle and keyhole.
     - `CatSelfHostedAndHomelabIcon` (`cat-self-hosted-and-homelab`): Server rack units with status LEDs.
     - `CatWebTemplatesAndStartersIcon` (`cat-web-templates-and-starters`): Browser window frame with page layout blocks.
     - `CatMobileAppsIcon` (`cat-mobile-apps`): Smartphone with app icons and speaker notch.
     - `CatAccessibilityIcon` (`cat-accessibility`): Universal human figure with outstretched arms.
     - `CatFunAndExperimentsIcon` (`cat-fun-and-experiments`): Chemistry flask with bubbling potion.
   - All icons:
     - Built on a 16×16 coordinate grid with `shapeRendering="crispEdges"`.
     - Strictly use `var(--color-pixel-*)` tokens or `currentColor`.
     - Accept standard SVG / `PixelIconProps` (`size`, `className`, `aria-hidden`, etc.).
     - Exported from `packages/ui/src/icons/index.ts`.
     - Mapped via `CATEGORY_ICONS` dictionary and accessible via `<CategoryIcon iconKey={cat.iconKey} />`.
