# [5.7] Showcase art and RSS

**Author:** Flash  
**Branch:** `flash/5.7-showcase-art-rss`  

## What changed

1. **16x16 Pixel Badges (`packages/ui/src/icons/BadgeIcons.tsx`, `PixelIcons.tsx`, `packages/ui/src/art/ShowcaseArt.tsx`)**:
   - Added 16x16 pixel definitions in `BadgeIcons.tsx`:
     - `"badge-showcase"`: Crystal gemstone standing on a display pedestal (`#73eff7`, `#38b764`, `#ffcd75`, `#3b5dc9`).
     - `"badge-closed-source"`: Coral padlock with silver shackle (`#ef7d57`, `#b13e53`, `#f4f4f4`, `#1a1c2c`).
   - Created `ShowcaseBadgeIcon` and `ClosedSourceBadgeIcon` in `PixelIcons.tsx` (viewBox 0 0 16 16, crisp pixel-art SVGs).
   - Created UI badge components in `packages/ui/src/art/ShowcaseArt.tsx`:
     - `<ShowcaseBadge />`: Distinctive accent badge carried by community showcases.
     - `<ClosedSourceBadge />`: Neutral badge with explicit copy `"Closed source: look, don't take"` (and compact variant `"Closed source"`).

2. **Showcase Empty-State Art (`packages/ui/src/icons/PixelIcons.tsx`, `packages/ui/src/art/ShowcaseArt.tsx`)**:
   - Created `ShowcaseEmptyIcon`: 32x32 pixel art exhibition vitrine under overhead gallery spotlights with floating sparkles, velvet cushion, and dual plinth pedestal.
   - Built `<ShowcaseEmptyArt />` and `<ShowcaseEmptyState />` with responsive layout variants (`page`, `card`, `inline`).
   - Enforced the strict ForkLift invariant: Showcases never get clone or fork wording. Empty state copy focuses on admiring creations, getting inspired, and sharing AI builds.

3. **Showcase OG Share Image Template (`packages/ui/src/art/ShowcaseOgTemplate.tsx`)**:
   - `renderShowcaseOgSvg(opts)`: Generates a 1200x630 vector SVG share image with top 16-bit pixel stripe, showcase header, category/stage indicators, title, story tagline, maker attribution with avatar plinth, AI tool tags, and upvote counters. Strictly zero clone/fork wording.
   - `<ShowcaseOgCard />`: React preview component rendering the share card.

4. **Showcase RSS Feed (`apps/worker/src/routes/feeds.ts`)**:
   - Added route handler `showcasesRss` on `GET /api/feeds/showcases.rss`.
   - Supports query filters: `?category=`, `?user=`, `?kind=`, `?tool=`.
   - Includes items with title, link (`/showcases/:slug`), maker attribution (`Built by ...`), AI tools used, stage, category, and upvote counts.
   - Guaranteed absence of fork/clone actions.
   - Added integration test suite in `apps/worker/test/integration/feeds.test.ts` verifying showcase RSS XML structure, draft filtering, category filtering, user filtering, and lack of fork/clone wording.

5. **Showcase Art Preview Route (`apps/web/src/features/pages/ShowcaseArtPreview.tsx`)**:
   - Created `/showcase-art-preview` showcasing the 16x16 badges, empty-state vitrine, OG share card, and live RSS endpoint link.

6. **Contract Request (`docs/contract-requests/flash-5.7-showcase-rss.md`)**:
   - Requested Opus to register `showcasesRss` in shared API routes (`packages/shared/src/api/routes.ts`) and export `./art` in `packages/ui/package.json`.
   - Re-exported art components via `packages/ui/src/icons/index.ts` so all agents can immediately import them via `@forkvlift/ui/icons`.

## How to test

1. **Unit & Integration Tests**:
   ```bash
   pnpm --filter @forkvlift/worker test
   ```
   All feed tests pass, including showcase RSS verification.

2. **Full Repo Checks**:
   ```bash
   pnpm check
   node scripts/check-owners.mjs
   ```

3. **Visual Verification**:
   - Run `pnpm dev` and visit `http://127.0.0.1:8789/showcase-art-preview`.
   - Verify badges, empty-state vitrine, and OG card render sharply at 375 px and 1440 px.
   - Fetch `http://127.0.0.1:8789/api/feeds/showcases.rss` to inspect the live RSS feed.
