# [1.14] Static pages + shared no-license disclaimer component

**Author:** Flash (Gemini 3.8 Flash, Antigravity)  
**Branch:** `flash/1.14-static-pages`

## What changed

1. **Shared No-License Disclaimer Components (`apps/web/src/features/pages/NoLicenseDisclaimer.tsx`)**:
   - `NoLicenseBanner`: Persistent banner component for unlicensed projects (used in Task 1.9 focus panel and Task 1.14 Licensing 101). Renders the exact `NO_LICENSE_DISCLAIMER.title` and `NO_LICENSE_DISCLAIMER.body` from `@forkvlift/shared`, along with a link to Licensing 101 and an optional prefilled GitHub issue link to request a license from the author.
   - `NoLicenseDisclaimerModal`: Accessible `<dialog>` modal using `@forkvlift/ui`'s `Modal` component for when users enable the "Show unlicensed projects" toggle (Task 1.10 filter drawer and settings). Uses the exact `NO_LICENSE_DISCLAIMER` text and includes confirm/cancel actions.
   - `apps/web/src/features/pages/index.ts` exports only the shared disclaimer components (`NoLicenseBanner`, `NoLicenseDisclaimerModal`) for other feature consumers.

2. **Static Pages (`apps/web/src/features/pages/StaticPages.tsx`)**:
   - `AboutPage` (`/about`): Comprehensive overview of ForkvLift's mission, 5 guiding principles, vibe-coding workflow, and clean CTA links using `buttonClasses`.
   - `LicensingPage` (`/licensing`): In-depth "Licensing 101 for Vibe-Coders" guide explaining why licenses matter, what "No license" means with the embedded `NoLicenseBanner` disclaimer, GitHub's Terms of Service vs. copyright law, breakdown of common licenses, and how to add a license.
   - `RulesPage` (`/rules`): Seven community rules. Rule 4 accurately reflects that authors are warned privately about committed secrets (not publicly flagged), while scripts that download and run code are flagged with a "Review before running" notice.
   - `PrivacyPage` (`/privacy`): Plain-English privacy policy. Explicitly notes that user's primary verified GitHub email is stored (for account linking/magic link), GitHub OAuth uses `read:user user:email` without keeping tokens, and self-service export/deletion is planned for task 2.10.
   - `TermsPage` (`/terms`): Terms of service explaining ForkvLift's role as a public index (not a code runner or host), user responsibility, code safety, and limitation of liability.
   - `DmcaPage` (`/dmca`): Copyright takedown policy directing notices to the repository issue tracker (`https://github.com/Cyberhex1/forkvlift/issues` with prefix `Takedown:`) with statutory notice requirements.

3. **Responsive and Accessibility Polish**:
   - Mobile-first layout verified down to 375 px with zero horizontal overflow.
   - Fixed interactive elements: avoided `<button>` inside `<a>` by using `<Link className={buttonClasses(...)}>`.
   - Keyboard navigable with focus rings.
   - Strict adherence to `@forkvlift/ui` tokens and zero hardcoded Tailwind default colors.
