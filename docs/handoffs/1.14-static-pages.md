# [1.14] Static pages + shared no-license disclaimer component

**Author:** Flash (Gemini 3.8 Flash, Antigravity)  
**Branch:** `flash/1.14-static-pages`

## What changed

1. **Shared No-License Disclaimer Components (`apps/web/src/features/pages/NoLicenseDisclaimer.tsx`)**:
   - `NoLicenseBanner`: Persistent banner component for unlicensed projects (used in Task 1.9 focus panel and Task 1.14 Licensing 101). Renders the exact `NO_LICENSE_DISCLAIMER.title` and `NO_LICENSE_DISCLAIMER.body` from `@forkvlift/shared`, along with a link to Licensing 101 and an optional prefilled GitHub issue link to request a license from the author.
   - `NoLicenseDisclaimerModal`: Accessible `<dialog>` modal using `@forkvlift/ui`'s `Modal` component for when users enable the "Show unlicensed projects" toggle (Task 1.10 filter drawer and settings). Uses the exact `NO_LICENSE_DISCLAIMER` text and includes confirm/cancel actions.
   - Re-exported via `apps/web/src/features/pages/index.ts`.

2. **Static Pages (`apps/web/src/features/pages/StaticPages.tsx`)**:
   - `AboutPage` (`/about`): Comprehensive overview of ForkvLift's mission, the 5 guiding principles (Public code honestly labeled, Credit the original, No dark patterns, Fun not corporate, Cheap to run), step-by-step vibe-coding workflow, and calls to action.
   - `LicensingPage` (`/licensing`): In-depth "Licensing 101 for Vibe-Coders" guide explaining why licenses matter, what "No license" means with the embedded `NoLicenseBanner` disclaimer, GitHub's Terms of Service vs. copyright law, breakdown of common licenses (permissive, public domain, copyleft), and instructions on how to add a license.
   - `RulesPage` (`/rules`): Seven community rules covering public code requirements, author attribution, zero-tolerance malware/exploit policy, leaked secrets, anti-spam, respectful conduct, honest metadata, and reporting procedures.
   - `PrivacyPage` (`/privacy`): Plain-English privacy policy emphasizing minimal data collection, zero sale of personal data, essential cookies, local storage usage, and GDPR/CCPA data deletion rights.
   - `TermsPage` (`/terms`): Terms of service explaining ForkvLift's role as a public index (not a code runner or host), user responsibility, code safety, submission terms, and limitation of liability.
   - `DmcaPage` (`/dmca`): Copyright takedown policy detailing 17 U.S.C. § 512 notice requirements, designated agent contact, and counter-notification process.

3. **Responsive and Accessibility Polish**:
   - Mobile-first layout verified down to 375 px with zero horizontal overflow.
   - Keyboard navigable with focus rings.
   - Strict adherence to `@forkvlift/ui` tokens and zero hardcoded Tailwind default colors.
