# 4.7 Alternatives directory

The Worker derives products from publicly listed projects' replaces arrays, groups case/spacing/punctuation variants by slug, and counts each project once. Non-Latin names get stable URL-safe identifiers. No price data is invented. Private, unpublished, hidden and deleted projects are excluded. The directory counts licensed projects; detail pages honor showUnlicensed and return a hidden count. Shared ProjectCard mapping preserves viewer state and WIP information.

The UI implements /alternatives search and /alternatives/:product with reusable cards, breadcrumbs, preference persistence and the exact shared no-license disclaimer. It handles loading, empty, API errors/retry and missing products. Keyboard product/panel navigation and reduced motion are covered.
