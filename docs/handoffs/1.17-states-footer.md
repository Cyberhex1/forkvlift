# [1.17] Empty, loading and 404 states; footer

**Author:** Flash (Gemini 3.8 Flash, Antigravity)  
**Branch:** `flash/1.17-states-footer`

## What changed

1. **Footer Component (`apps/web/src/features/pages/Footer.tsx`)**:
   - Polished layout with top 16-bit pixel accent bar (`pixel-2` through `pixel-11`).
   - Four responsive columns: Brand & mission summary, Explore links, Community links, and Guides & Legal.
   - Bottom copyright, licensing credit, and legal links.
   - Fully responsive down to 375 px (stacks cleanly, then expands to a 4-column layout on desktop).
   - Semantic `<footer>` and `<nav>` with full keyboard accessibility.

2. **404 Not Found Page (`apps/web/src/features/pages/NotFoundPage.tsx`)**:
   - Clubhouse-themed 404 page ("404: Nothing to fork here").
   - Inline crisp pixel art broken forklift (`PixelBrokenForklift`).
   - Clear copy explaining that the project or page could not be located.
   - Primary and secondary navigation buttons ("Back to the feed", "About ForkvLift") plus helpful shortcuts (Licensing 101, Rules, Privacy, Terms).

3. **Reusable States (`apps/web/src/features/pages/States.tsx`)**:
   - `EmptyState`: Reusable empty state for catalog feeds, search queries, studio kanban columns, and profile collections. Supports `page`, `card`, and `inline` variants.
   - `LoadingGridState`: Responsive skeleton grid mimicking project cards (1 col at 375 px, up to 4 cols on desktop) with pulse animation (respects `motion-reduce`).
   - `LoadingScreen`: Accessible full-screen / section loading spinner with screen-reader text.
   - `LoadingPanelSkeleton`: Detail panel skeleton for `/p/:slug` loading.
   - `ErrorState`: Friendly error box with retry button and home link.
   - `UnlicensedHiddenNotice`: Inline notification for "N unlicensed projects hidden · Show them" per product plan.
   - `PixelCrate`, `PixelBrokenForklift`: Crisp pixel SVGs using pure `--color-pixel-*` tokens.

4. **Pixel Icons (`packages/ui/src/icons/PixelIcons.tsx` & `index.ts`)**:
   - Created pixel icon set (`EmptyCrateIcon`, `BrokenForkliftIcon`, `SearchEmptyIcon`, `WarningShieldIcon`).
   - Submitted contract request `docs/contract-requests/flash-1.17-export-icons.md` so Opus can export them from `@forkvlift/ui`.

## How to test

1. Run `pnpm dev` and visit `http://127.0.0.1:8789`.
2. Inspect the footer at the bottom of the page across desktop (1440 px) and mobile (375 px).
3. Visit an invalid URL (e.g. `http://127.0.0.1:8789/nonexistent-route`) to verify the 404 page.
4. Run `pnpm check` to ensure all checks (typecheck, lint, tests, build, and check-no-fixtures) pass.
