# [1.7] Discovery cron, candidate queue, admin API: Opus

## What changed

- **Discovery** (`core/curation/discovery.ts`, cron every 6 hours):
  - Runs a GitHub Search for repos created in the last 90 days with the topics `vibe-coding`, `vibecoding`, `built-with-claude`, `claude-code` or `ai-generated` and at least 3 stars.
  - Diffs the awesome-list watchlist (`0xWelt/Awesome-Vibe-Coding`) for new repo links. Only the links are used; their text is never copied.
  - Skips anything already queued, rejected or listed, and adds at most 25 new repos per run, each queued as a `candidate.discover` job.
  - **Doesn't run on preview/production until a `GITHUB_TOKEN` secret is set.** There's no Reddit access of any kind.
- **Candidates** (`core/curation/candidates.ts`, `score.ts`):
  - **Score:** 0–100 from star velocity, stars, README, demo, screenshots, license (a bonus only), recent activity, and penalties for archived repos and forks.
  - **Check chips:** license (shown, never required), README, unchanged fork (left unchecked for forks; compare by hand), archived. The secrets and malware chips stay "not run" until 1.6.
  - **Proposed card:** an editable draft built from the repo.
- **Admin API** (needs Cloudflare Access, or a local session admin):
  - `listCandidates`: filter by status (a snooze that has run out shows as pending again); sort by score, newest or stars.
  - `importCandidate`: the paste-a-link importer. A Reddit post URL is stored as the found-via credit (`reddit_link`). Only the GitHub data is fetched.
  - `decideCandidate`:
    - **Approve and publish / approve as draft:** needs a category, re-ingests the repo, and creates a curated project with no author, marked unclaimed.
    - **Reject:** keeps the reason and never suggests that repo again.
    - **Snooze:** for N days.
  - `bulkDecideCandidates`: skips any it can't approve and returns the number updated.
  - `upsertCategory`: create, rename, approve, or merge into another category (which moves its projects and sub-categories).
  - `setStaffPick`: staff pick plus a featured slot.
  - `adminStats`: signups, projects, unlicensed count, queue size. Fork clicks and chat counts are 0 until tasks 2.2 and 3.1.
  - `auditLog`: every action above is logged. Console actions record the Access email in `details.actor`.
- **`POST /api/projects/:slug/claim`:** the repo's GitHub owner (or a public member of the owning org) can claim a curated project and become its listed author. Claims are logged.
- **Refactor:** `insertProject()` is shared by the submit flow and curation.
