# [4.11] Subscription Savings Counter Widget

## What changed
- Implemented `savingsStats` route (`GET /api/stats/savings`) in `apps/worker/src/routes/feeds.ts`.
- Computes verified monthly subscription savings by cross-referencing listed, licensed projects declaring `replaces` against `paid_products` (e.g. Notion, Trello, Airtable) multiplied by active community fork counts. No inflated math; unlicensed projects excluded.
- Created `SavingsCounter` widget component in `apps/web/src/features/pages/SavingsCounter.tsx` and exported it from `features/pages/index.ts`.
- Integrated `SavingsCounter` on the About page (`/about`) with full mobile responsiveness (375 px friendly), clear calculation transparency disclosure, and link to `/alternatives`.
- Added integration test coverage in `apps/worker/test/integration/feeds.test.ts`.

## How to test
1. Run `pnpm test` (or `pnpm check`).
2. Visit `http://localhost:8789/about` in dev to view the savings counter widget.
3. Verify responsive layout at 375px and 1440px across light, dark, and retro themes.
