# 4.4 Client-side agent starter prompt

The project panel now always generates an Agent prompt from getProject data: name, repository, stage, stack, description, bounded plain-text README summary, SPDX/summary, and what works/what is missing. Author content is quoted JSON context, explicitly treated as data. Missing fields request repository verification rather than invented setup commands or file paths. The goal placeholder asks the viewer to specify their change.

Licensed projects instruct the agent to respect the actual LICENSE and attribution. Unlicensed projects include the exact shared NO_LICENSE_DISCLAIMER and stop at assessment/permission before reuse; they offer no clone command. The old optional server starterPrompt display is replaced. No AI call, new route, shared dependency, fixture or core change.

The selectable read-only textarea is keyboard accessible. Copy has progress, success and error/manual-copy feedback. Project loading/error remain handled by the panel; missing README/stack/status have explicit prompt fallbacks.
