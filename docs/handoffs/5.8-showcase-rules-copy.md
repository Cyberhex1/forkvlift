# [5.8] Showcase rules and help copy

**Author:** Flash  
**Branch:** `flash/5.8-showcase-rules-copy`  

## What changed

1. **Plaza #showcase Auto-Post Copy & Rules Constants (`apps/web/src/features/pages/showcaseCopy.ts`)**:
   - `PLAZA_SHOWCASE_COPY`:
     - Room ID: `"showcase"`.
     - Composer opt-in label: `"Post to Plaza #showcase"`.
     - Description: `"Share a live announcement card in the #showcase chat room so builders can see what you made."`.
     - `formatAutoPost`: Generates structured markdown messages for Plaza chat with maker attribution, tagline, AI tools used, closed-source status, and showcase link (strictly no clone/fork actions).
     - `formatOneLiner`: Compact single-line notification helper.
   - `SHOWCASE_RULES`:
     - `whatsAllowed`: Working web apps, mobile apps, games, desktop tools, SaaS, short films, and generative art. Public repo not required; closed-source welcome; plain commercial links allowed (no paid placements).
     - `honestAiUse`: Truthful attribution of AI models, prompts, workflows, and limitations.
     - `linksAndSafety`: Priority for web demos and app store links; advisory warning for executable downloads; zero tolerance for malware or deceptive installers.
     - `lookDontTake`: Clarifies that showcases are for inspiration and storytelling, not code reuse.
     - `noImpersonation`: Authentic authorship requirement.
   - `SHOW_OFF_SATURDAY`:
     - Official name: `"Show-off Saturday"`.
     - Description and short rules: 1 showcase entry per maker, 1 vote per person across the ballot, no self-voting, anti-sybil safeguards, and "Showcase of the Week" recognition.
   - `DOWNLOAD_SAFETY_NOTICE`: Standalone advisory warning for binary downloads ("Review before running").
   - Strict preservation and re-export of `NO_LICENSE_DISCLAIMER` from `@forkvlift/shared`.

2. **Showcase Help Page (`apps/web/src/features/pages/ShowcaseHelpPage.tsx`)**:
   - Added `/help/showcases` with mobile-first responsive layout (tested at 375 px and 1440 px).
   - Side-by-side comparison cards: Catalog Project (open-source, reusable, forkable) vs. Showcase (look, don't take, media & story first).
   - Explains what's allowed, honest AI attribution guidelines, links & downloads safety caution card.
   - Detailed breakdown of Show-off Saturday rules.
   - Open-source conversion guide explaining how a closed showcase can later be listed in the catalog with 1 click while preserving upvotes and comments, incorporating `NoLicenseBanner` with unaltered `NO_LICENSE_DISCLAIMER`.

3. **Showcase Rules Section on Rules Page (`apps/web/src/features/pages/StaticPages.tsx`)**:
   - Added `Showcase rules` section with anchor `#showcases` to `RulesPage`.
   - Embedded link to `/help/showcases`.

4. **Routes and Exports (`apps/web/src/features/pages/routes.tsx`, `index.ts`)**:
   - Registered `/help/showcases` in `pagesRoutes`.
   - Re-exported `ShowcaseHelpPage` and all copy constants/functions from `apps/web/src/features/pages`.
