# 5.4 Showcase feed and page

Sol built `/showcase` and `/showcase/:slug` using the shared contracts and token components. The media-first grid supports semantic query/relevance, trending/new/top, categories, kind, AI tools, staff picks and paging. Pages show gallery images and controlled video, allowlisted embeds, external links with download advice, descriptions, build stories, credits, code links, saves, upvotes, comment/reply posting and deletion. Owner self-voting is disabled; listing a public repo validates ownership and licensing on the server.
