# 1.11 Submit form

## Changes
- Signed-in paste-a-GitHub-URL flow with auto-filled repository preview, exact API warnings, license summary/shared no-license disclaimer, README preview and ownership checks.
- Editable metadata, category, stage, WIP works/missing/help, public/private setting, build facts, platform/AI tools, links, tags, replaces, template and fork lineage. Idea-only submissions force private visibility.
- Typed upload reservation and raw `putUpload` calls preserve Content-Type and attach keys only after success. Client validates thumbnail/gallery types, size and count; failed uploads can be retried by choosing the file again. Remove controls detach keys from this submission.
- Feature-local explicit Turnstile integration with script failures, expiration, retry, cleanup and fresh verification after every submission attempt. No new dependency or shared component.
- Shared create-body validation; pending/failed submission retains inputs. Duplicate 409 claimable responses offer Claim it; preview duplicates link to the existing listing, with claim offered only after fetching an unclaimed curated detail. Server ownership remains authoritative.

## Validation
`pnpm check` passes (175 unit/integration tests, typecheck, lint, builds and no-fixtures). Browser suite passed 25 tests with one intentional desktop touch skip; after adding licensed/empty settings coverage and tightening claims, all 12 submit tests pass at 375 and 1440 px. Tests cover signed-out/ownership, no license/WIP, loading/error/retry, raw uploads and failure, private ideas, validation, expired tokens, rate limits, claim conflicts and unavailable categories/config. Turnstile SDK is mocked only inside e2e tests. Computer use previewed and submitted the fixture repo at desktop width, and saved a private fixture idea at mobile width using the actual configured Turnstile test key.

Run `pnpm dev`, sign in at `/api/dev/login?as=fx-ada`, then visit `/submit`. Paste a repository URL, preview, pick a category and stage, edit fields, upload optional files and submit. For a private idea, select the checkbox instead of pasting a URL. Fixture responses are provided by the API, never imported by the client.
