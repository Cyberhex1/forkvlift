## How to test

1. Ensure the dev server is running with `USE_FIXTURES=false`:
   ```bash
   pnpm dev
   ```
2. Run the seed import script with an admin session cookie:
   ```bash
   SEED_COOKIE=<admin-session-token> node scripts/seed/import.mjs
   ```
3. Inspect `data/seed/import-report.md` for output summary and results table.
4. Run `pnpm check` to ensure all typechecks, lint, tests, and builds pass.
