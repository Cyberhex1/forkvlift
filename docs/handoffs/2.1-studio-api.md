# [2.1] Studio API: Opus

## What changed

- `core/studio.ts` + `routes/studio.ts`: every Studio route is real now.
  - **Board:** created on first visit with Idea / Develop / Bug fix / Ready for release, and private to its owner. Other users get a 404.
  - **Columns:** add (up to 12), rename, recolor (`pixel-0`…`pixel-15` tokens only; anything else is a 400), collapse, set a WIP limit, reorder (send every column id exactly once), and delete. Deleting a column moves its cards to the end of the first remaining column, and the last column can't be deleted.
  - **Cards:** ideas or linked projects (the user's own only; one card per project), up to 500 per board. Moves renumber positions so they always run 0…n−1 with no gaps.
    - **WIP limits are enforced:** 409 with `details.wipLimit` on add or move.
    - **Stage and Public/Private on a linked card are the project's own:** publishing from any column publishes the project, and the WIP card shows its Studio column title.
    - **Idea cards with no repo** stay private (400 if you try to publish one).
  - **Planning tools:** `getPlan`/`updatePlan` (checklist, Markdown notes, "looking for help with", which also syncs to the project, saved prompts, GitHub issues toggle) plus a roadmap. Editing the roadmap keeps vote counts for items that survive. New items get server ids.
  - **`POST /api/projects/:slug/roadmap/:itemId/vote`:** public upvotes on a listed project's roadmap, one per user.
- Integration tests can turn off the write rate limits with `DISABLE_RATE_LIMITS` (set only in `vitest.integration.config.ts`).

## For Sol (2.6, 2.7)

- **Moves:** be optimistic, but roll back on a 409 (WIP limit) or 404.
- **Positions** are indexes inside the target column after the move.
- **Roadmap edits:** send the whole list. Keep the existing `id`s; new items can use any temporary id.
