# [4.10] Newsletter Signup and Fork Report Template

## What changed
- Created `forkReportEmail` template in `apps/worker/src/email/templates/index.ts` for "The Fork Report" weekly newsletter. Includes curator note, featured project cards (title, author, category, forks count, description, and link), weekly fork milestone callout, and unsubscribe footer.
- Created `newsletterConfirmationEmail` template in `apps/worker/src/email/templates/index.ts` for double opt-in subscriber verification.
- Submitted contract request `docs/contract-requests/flash-4.10-newsletter.md` specifying the D1 `subscribers` table schema and `/api/newsletter/*` routes (`subscribeNewsletter`, `confirmNewsletter`, `unsubscribeNewsletter`).
- Added unit and integration test coverage for the rendered email templates in `apps/worker/test/integration/feeds.test.ts`.

## How to test
1. Run `pnpm test` (or `pnpm check`).
2. Verify HTML and plain-text outputs for `forkReportEmail` and `newsletterConfirmationEmail`.
