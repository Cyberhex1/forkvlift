## How to test

Run the fixture web server and admin server. Sign in at `/api/dev/login?as=fx-ada`, visit `/resources`, and open Share a resource. Attach .md/.txt/.zip files, remove one, and share. Each file must be non-empty and at most 10 MB, with at most 50 attachments. Scripts must be inside a ZIP.
