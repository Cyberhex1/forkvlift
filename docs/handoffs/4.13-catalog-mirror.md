# [4.13] Open Catalog Data Mirror

## What changed
- Created `project.schema.json` in `data/seed/` defining the JSON schema for open project submissions and catalog records.
- Authored `PROJECT_SCHEMA.md` documenting all required and optional project metadata fields with an example JSON record.
- Built `validate-pr.mjs` in `scripts/seed/` to validate project submissions against the schema, category taxonomy (`categories.json`), slug conventions, and GitHub repository URL formats.
- Authored `MIRROR_README.md` in `data/seed/` detailing the mirror repo layout, automated nightly D1 sync, and step-by-step instructions for submitting projects by GitHub pull request.
- Submitted contract request `docs/contract-requests/flash-4.13-catalog-mirror.md` specifying the Worker nightly export cron job and PR ingestion hook.

## How to test
1. Run `node scripts/seed/validate-pr.mjs` with sample valid and invalid JSON payloads.
2. Run `pnpm check`.
