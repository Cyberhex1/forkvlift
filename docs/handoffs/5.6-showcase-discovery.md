# 5.6 Showcase discovery and admin

The home catalog includes showcase discovery and the most recent published staff pick as Showcase of the week. Profiles have a paged Showcases tab. Project panels and resource pages show credited showcases (hidden when empty), and Has this been built displays semantic showcase matches even when there are no catalog matches. All use the same media cards and clear Showcase/Closed source labels.

Admin `/showcases` searches builds and toggles setShowcaseStaffPick with pending/error feedback. The existing generic moderation queue supports showcase and showcase_comment labels, target links, hide/resolve and dismiss. Showcase pages now expose report buttons for builds and comments.

Signed-out browse, fx-ada Studio and fx-admin moderation are covered, plus long report text, keyboard and reduced motion. `pnpm check` passes (5 shared, 182 unit, 176 integration, typecheck/lint/build/no-fixtures).
