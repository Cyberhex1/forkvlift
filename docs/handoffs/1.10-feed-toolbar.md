# 1.10 Feed grid and toolbar

## Changes
Sticky responsive toolbar with feed and header search, eight sort options, category/subcategory and metadata filters in a shared Drawer. Search/filter/sort state round-trips through the URL and browser history. Typed cursor pagination loads on intersection and retains an accessible Load more button; page failures preserve existing results and offer retry. Duplicate IDs are removed across pages.

Unlicensed listings remain hidden unless `usePreferences().showUnlicensed` is enabled. URL flags cannot bypass this preference. The hidden-count note and switch open the exact shared disclaimer on first use; cancellation leaves the preference off. Saving account preferences handles pending/errors.

## Validation and test steps
`pnpm check` passes; `pnpm test:e2e --workers=2` passes (21 passed, 1 intentional desktop touch-only skip). The six new toolbar executions cover filters/search/sorts, history/reload, disclaimer cancel/accept/remembering, invalid URL, loading/empty/error, and pagination failure/retry at 375 and 1440 px. Computer use exercised the mobile drawer, WIP filtering, licensing opt-in/off, loading/empty/error via the test-only proxy, and desktop sorting.

Start `pnpm dev`, visit `/`, open Filters and choose a stage/category, apply, search and sort; copy/reload the URL or use Back. Turn Show unlicensed projects on, cancel, then accept; turn it off and on again. Use `node e2e/browser-state-proxy.mjs` and `http://127.0.0.1:8798/__qa?mode=empty` (or error/loading) for isolated browser failure states. This proxy never ships.
