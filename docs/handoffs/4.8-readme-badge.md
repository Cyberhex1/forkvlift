# [4.8] Live README Badge

## What changed
- Implemented `readmeBadge` route (`GET /api/badge/:slug`) in `apps/worker/src/routes/feeds.ts`.
- Serves dynamic SVG badges displaying the site name, fork count, and upvote count, linking back to the project page on ForkLift.
- Added HTTP cache headers: `Cache-Control: public, max-age=300, stale-while-revalidate=86400` and `X-Content-Type-Options: nosniff`.
- Added integration test coverage in `apps/worker/test/integration/feeds.test.ts`.
- Submitted contract request `docs/contract-requests/flash-4.8-readme-badge-ui.md` for Sol to include the copy snippet box on the Project Panel.

## How to test
1. Run `pnpm test` (or `pnpm check`).
2. In dev, request `http://localhost:8789/api/badge/<project-slug>` and verify SVG rendering and headers.
