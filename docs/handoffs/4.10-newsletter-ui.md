# [4.10] Newsletter Signup UI and Confirmation Pages

## What changed
- Built reusable `NewsletterBox` component in `apps/web/src/features/pages/NewsletterBox.tsx`:
  - Supports `footer` (compact responsive strip), `section` (full card for About and guide pages), and `standalone` layouts.
  - Integrates Cloudflare Turnstile bot verification via `SubmitVerification`.
  - Implements complete state handling:
    - Normal input with email validation and responsive submit button.
    - Pending confirmation (`status === "pending"`): explains double opt-in verification link has been emailed.
    - Already subscribed (`status === "confirmed"`): confirms active subscriber status.
    - Error handling with accessible `role="alert"` messages and retry/turnstile resets.
- Added newsletter signup box and "The Fork Report" link to `apps/web/src/features/pages/Footer.tsx`.
- Added a dedicated "The Fork Report" weekly dispatch section with signup box in `apps/web/src/features/pages/StaticPages.tsx` (About page).
- Implemented `NewsletterConfirmPage` (`/newsletter/confirm` and `/newsletter?confirm=TOKEN`) in `apps/web/src/features/pages/NewsletterConfirmPage.tsx` with token verification, loading spinner, confirmed success state, and error handling with inline resubscribe option.
- Implemented `NewsletterUnsubscribePage` (`/newsletter/unsubscribe` and `/newsletter?unsubscribe=TOKEN`) in `apps/web/src/features/pages/NewsletterUnsubscribePage.tsx` with user-confirmation prompt (safeguarding against automatic email prefetch scanners), unsubscription execution, and resubscribe option.
- Implemented `NewsletterPage` (`/newsletter`) in `apps/web/src/features/pages/NewsletterPage.tsx` providing an overview of weekly pillars (Fresh Releases, Fork Lineage, Open Replacements) and routing `?confirm=` and `?unsubscribe=` links seamlessly.
- Wired all routes into `apps/web/src/features/pages/routes.tsx` and exported components in `apps/web/src/features/pages/index.ts`.

## How to test
1. Run `pnpm dev` and visit `http://127.0.0.1:8789/newsletter`.
2. Enter an email and submit with Turnstile verification. Check pending and confirmed states.
3. Test confirmation route: `http://127.0.0.1:8789/newsletter?confirm=any_token_string`.
4. Test unsubscription route: `http://127.0.0.1:8789/newsletter?unsubscribe=any_token_string`.
5. Check footer on any page (e.g. `http://127.0.0.1:8789/about`) at both 375 px and 1440 px.
