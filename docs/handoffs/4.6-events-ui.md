# 4.6 Community events UI

Browse `/events`, `/launches` and `/jams`; filter by type/status and open event details. Event pages show server windows and status, rules, featured project for Fork Friday, eligible project/showcase pickers, entry submissions and withdrawal, and paged leaderboards with voting/retraction. Show-off events use the showcase entry routes and never offer catalog fork actions. Project choices exclude unlicensed and already entered builds; showcase choices exclude drafts. Self-voting is disabled, permission/window flags come from the server, and vote totals are refetched rather than computed locally.

Admin `/events` schedules all four event kinds, selects featured catalog projects, edits wording/future deadlines and cancels. Unchanged deadlines are omitted so wording can be edited after submissions close. Ended results cannot be cancelled. The catalog links to events.
