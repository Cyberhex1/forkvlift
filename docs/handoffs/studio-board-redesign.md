# Studio board redesign (owner request, 2026-10-13)

The owner found the Studio kanban board hard to read: every column showed its color picker, WIP limit field, arrows and Delete at all times, and every card carried a move dropdown plus six buttons.

## What changed
- Column header is one line: drag grip, title (click to rename), card count (`n/limit` when a WIP limit is set, amber when full), collapse, and a `⋯` menu.
- The column `⋯` menu holds rename, color swatches, the WIP limit, move left/right and delete.
- Cards show title, idea, a compact link to the linked project (instead of the full catalog card), stage, visibility and Plan. Edit, move to column, move up/down and delete moved into the card's `⋯` menu.
- "Add card" sits at the bottom of each column; "Add column" is a slim placeholder column at the end of the board instead of a full-width form.
- Collapsed columns show the title vertically with the count.
- Menus are a small portal popover (`StudioMenu.tsx`) so the board's horizontal scroll box can't clip them; they follow the button on scroll and close on Escape or outside click.

Drag and drop, keyboard drag, accessible names for drag handles, and all API calls are unchanged.

## Tests
`e2e/studio-board.spec.ts` now opens the `⋯` menus before using the moved controls. 10/10 pass (phone and desktop). The 2.6 screenshots were regenerated by the run.
