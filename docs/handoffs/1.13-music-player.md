# [1.13] Elevator music player: mute, volume, skip, remembered choice, starts on first click

**Author:** Flash (Gemini 3.8 Flash, Antigravity)  
**Branch:** `flash/1.13-music-player`

## What changed

1. **Web Audio Synthesizer Engine (`apps/web/src/features/music/synth.ts`)**:
   - Zero-external-dependency procedural synthesis using Web Audio API (`AudioContext`, `BiquadFilterNode`, `GainNode`, and `OscillatorNode`).
   - Warm, mellow elevator acoustics with a 1400 Hz low-pass filter.
   - Three original CC0 compositions:
     - Track 1: *Lobby Bossa* (110 BPM, Cmaj7 - Am7 - Dm7 - G7 bossa lounge).
     - Track 2: *Penthouse Chill* (90 BPM, Fmaj7 - Em7 - Dm7 - Cmaj7 lo-fi vibraphone).
     - Track 3: *Warehouse 8-Bit* (124 BPM, G - Em - C - D upbeat chiptune groove).
   - Strict autoplay compliance: audio context initializes and starts playback only on user click.
   - Master volume scaling, mute gain clamping, and polyphonic note scheduling.

2. **Music Button & Control Popover (`apps/web/src/features/music/MusicButton.tsx`)**:
   - Sits in the header bar slot (`<MusicButton />` in `apps/web/src/app/Header.tsx`).
   - Animated retro 3-bar equalizer indicator that pulses when playing and respects `usePreferences().motionReduced`.
   - Compact and fully responsive at mobile (375 px) up to desktop.
   - Expanded control card with:
     - Now Playing card with track title, style subtitle, and BPM.
     - Play / Pause button.
     - Skip next track button.
     - Mute / Unmute toggle.
     - Interactive volume slider (0 to 100%).
     - Track picker buttons.
   - Remembers user preferences in `localStorage` (`fv-music-muted`, `fv-music-volume`, `fv-music-track`).
   - Full keyboard accessibility (focus rings, Escape key to close popover, ARIA attributes).

3. **Music Credits (`apps/web/public/music/CREDITS.md`)**:
   - Track details, composition notes, and explicit CC0 1.0 Universal dedication.

## How to test

1. Run `pnpm dev` and open `http://127.0.0.1:8789`.
2. Notice that no music autoplays upon loading.
3. Click the "Music" button in the header bar:
   - The elevator music player panel opens.
   - Click "Play" or click any track to start playback.
   - Test volume slider, mute/unmute, and skip buttons.
   - Refresh the page to verify that volume, mute, and selected track preferences persist in `localStorage`.
4. Test responsiveness at 375 px width in DevTools.
5. Verify `pnpm check` passes with all tests and builds clean.
