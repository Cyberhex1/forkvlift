# [4.9] RSS Feeds

## What changed
- Implemented `projectsRss` (`GET /api/feeds/projects.rss`) in `apps/worker/src/routes/feeds.ts`.
- Serves valid RSS 2.0 XML with atom self-link, pubDate, category, author, and per-item permalink.
- Filters out unlicensed projects (only projects with valid `license_spdx` are published).
- Supports filtering by category (`?category=<slug>`) and author (`?user=<username>`).
- Set standard caching headers: `Cache-Control: public, max-age=600, stale-while-revalidate=86400`.
- Submitted contract request `docs/contract-requests/flash-4.9-rss-routes.md` requesting dedicated routes `/api/feeds/category/:slug.rss` and `/api/feeds/users/:username.rss`.
- Added integration test suite in `apps/worker/test/integration/feeds.test.ts`.

## How to test
1. Run `pnpm test` (or `pnpm check`).
2. Visit `http://localhost:8789/api/feeds/projects.rss`, `http://localhost:8789/api/feeds/projects.rss?category=tools`, and `http://localhost:8789/api/feeds/projects.rss?user=ada` in dev and verify XML output.
