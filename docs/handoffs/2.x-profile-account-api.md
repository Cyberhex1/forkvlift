# Profile and account API: Opus

Backend for Sol's 2.8 (profile page) and Flash's 2.10 (settings).

- **`getProfile`:** the profile itself, bio, location, links, and stats: listed projects, total GitHub forks of the user's work, and how many distinct people forked their projects on the site. Also badges, the showcase (pinned order; unlicensed projects shown only to the owner), join date, and viewer flags (`isSelf`, `following`, `blocked`). `online` stays `null` until the Plaza (3.2).
- **`updateMe`:** username (case-insensitive and unique; reserved names like `admin` and `settings` are refused), display name, bio, location, links.
- **`setShowcase`:** up to 6 of your own listed projects, in order.
- **`updateAvatar`:** saves the 16-bit avatar config.
- **`exportData`:** always `ready`, pointing at the new **`GET /api/me/export`**, which downloads `forklift-export-<date>.json` with everything the user made.
- **`deleteAccount`:** needs the username typed to confirm. It removes sessions, profile, avatar, follows, blocks, collections, the Studio, notifications and votes. It soft-deletes the user's projects, comments, posts and sent message bodies, then anonymizes the user record ("Deleted user", no email, no GitHub link). Threads that others replied to stay up, credited to "Deleted user".
- **`updateSettings`** now creates the profile row if it's missing.

Tests: `test/integration/account.test.ts`.
