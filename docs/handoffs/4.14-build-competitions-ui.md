# 4.14 Build competitions UI

Browse `/competitions`, read round rules/eligibility/prizes/criteria/judges, enter through the existing event flow, and view published awards at `/competitions/:slug/winners`. Unannounced results remain empty. Assigned judges use `/competitions/:slug/judging`: partial scorecard drafts, criterion bounds, private notes, error retention, final review and immutable submission. Own/conflicting entries and closed judging are disabled.

Admin `/competitions` creates prize rounds on project events, sets prizes/criteria/judges before opening, edits wording, cancels with confirmation, displays server weighted totals, provides assigned-judge scorecards, and reviews/version-checks final awards before publishing. Prize values/sponsors are display only; no payment, collection or payout flow exists.
