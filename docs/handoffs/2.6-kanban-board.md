# 2.6 Studio kanban board

## Changes
Private authenticated board at /studio using the typed Studio API. Pointer/touch handles and keyboard drag (Space/Enter, arrows, drop; Escape cancels) move cards and reorder columns. Explicit move selects and reorder buttons provide an alternative. Moves and column reorder are optimistic, serialized while saving, and roll back on API errors including WIP-limit 409s.

Columns support inline rename, collapse to a slim strip, pixel-0 through pixel-15 colors, add/delete and WIP limits with warnings. Cards support private ideas or links to your listed projects, title/idea/stage editing, deletion, and Public/Private toggles; repository-free ideas cannot be published. Linked projects reuse ProjectCard. A feature-local includeUnlicensed option allows owner-only Studio views to show their unlicensed work while public lists retain the preference filter. No shared entity fields were added.

The dnd-kit dependencies were requested first and added by Opus in contracts PR #28. Sortable animation is disabled under motionReduced; card flips already use the reduced-motion preference. Publishing and WIP-limit enforcement remain authoritative on the backend.
