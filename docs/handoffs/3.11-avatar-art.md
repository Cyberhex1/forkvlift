# [3.11 polish] Avatar Art and Customization Options

## What changed
- Expanded `PixelAvatar.tsx` in `packages/ui` with new hairstyles (`ponytail`, `afro`, `mohawk`, `undercut`, `dreads`, `bangs`), outfits (`suit`, `sweater`, `cyberpunk`, `tank`), and accessories (`sunglasses`, `beanie`, `crown`, `eyepatch`, `cat-ears`, `halo`), with crisp shading details (collar trims, hoodie pocket & strings, lapels, earphone pads, scarf patterns).
- Improved label formatting in `AvatarBuilder.tsx` so kebab-case accessories like `cat-ears` display nicely as "Cat Ears".
- All art strictly uses the 16×16 grid and palette tokens (`pixel-*`, `skin-*`, `hair-*`).

## How to test
1. Navigate to `/settings/avatar` (while logged in).
2. Browse through each hair style, outfit, color, and accessory preview in the avatar builder.
3. Test "Shuffle" and "Save". Verify avatar previews update correctly across the site (e.g. Plaza and Profile).
4. Run `pnpm check`.
