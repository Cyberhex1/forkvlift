# 1.9 Focus panel

## Changes
- Shareable `/p/:slug` modal above the feed; closing restores the previous feed URL and keyboard focus.
- API-backed gallery, build facts, repository stats, health breakdown, WIP details, fork lineage, author, sanitized README and paginated comments.
- Licensed projects expose clone/starter-prompt copy and supported development links. Unlicensed details show the exact shared disclaimer and permission links, with fork tooling withheld.
- Typed upvote, collection-save and report flows, including pending and failure states. Media never autoplays; reduced motion replaces animated GIF previews with an explicit link.

`pnpm check` passes (175 unit/integration tests, typecheck, lint, production builds and fixture isolation). `pnpm test:e2e --workers=2` covers opening/closing, URL and focus restoration, signed-in mutations, gallery fallbacks, reduced motion, all licensing/stage variants, loading/error/retry/404, and both viewport widths. Computer-use checks opened the WIP and unlicensed panels and inspected the mobile layout; API failures are injected only by the test suite.
