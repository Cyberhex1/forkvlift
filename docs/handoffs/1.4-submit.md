# [1.4] Submit-by-URL backend: Opus

## What changed

- **`POST /api/projects/preview`:** paste a GitHub URL and get back auto-filled fields: name, description, license, stars, language, social image and README. It also returns `ownedByViewer`, `alreadyListed`, and warnings for: no license (the project will be hidden by default), no README, archived, or the repo is a fork.
- **`POST /api/projects`** (needs Turnstile):
  - **Ownership:** the repo must belong to the submitter, either as their own GitHub account or an org where they're a *public* member. Anyone else's repo goes through curation.
  - **Duplicates:** returns 409. If the existing listing is curated, the error includes `details.claimable: true`.
  - **Unlicensed repos** are accepted and stay out of default lists.
  - **Idea-only** projects (`repoUrl: null`) stay private until they have a repo.
  - **Other details:** slugs are unique (old ones are never reused), tags are normalized (max 5), fork lineage is recorded (`forkedFromSlug`), the health score is computed, the search index is updated, and the thumbnail falls back to GitHub's OG card.
- **`PATCH /api/projects/:slug`:** author or admin only. Partial updates. Publishing for the first time sets `published_at`. Tags are replaced. The search index is re-synced.
- **`DELETE /api/projects/:slug`:** soft delete, removed from search.
- **Fix:** the `xss` CommonJS import now works inside workerd as well as Node.

## For Sol (1.11)
