# Sprites (owner: Flash)

16-bit avatar layers and Plaza art.

- Sprite sheets as PNG with a JSON frame map next to each sheet (`<name>.png` + `<name>.json`).
- Layers: `hair`, `outfit`, `color`, `accessory` — the keys used by `AvatarConfig` in `packages/shared`.
- Palette: the `pixel-0` … `pixel-15` tokens in `../tokens.css`.
